# 日志分析技能 · 0.2.0-beta.1

分析本地日志，生成可回查原文的离线链路报告；结果有偏差时，生成脱敏反馈供你检查。两个技能独立使用，只在显式调用时运行，不依赖 DSH。

需要 Python 3.9+，无第三方依赖；报告用浏览器打开。

## 安装与调用

按宿主选择一组，把技能目录复制到对应位置：

| 宿主 | 来源 | 安装位置 | 调用方式 |
|---|---|---|---|
| Codex | `codex/` | `~/.codex/skills/` | `$unified-log-analysis`、`$unified-log-feedback` |
| Claude Code | `claude/` | `~/.claude/skills/` | `/unified-log-analysis`、`/unified-log-feedback` |
| 其他 AI | `manual/` | 任意本地目录 | 让 AI 读取对应技能的 `MANUAL.md` |

首次使用时，确认未点名不会自动触发，并打开一次生成的 `report.html`。

## 使用

分析时提供日志路径和问题，例如 Claude Code：

```text
/unified-log-analysis <日志路径> 整理这次消息发送的链路
```

Codex 用 `$unified-log-analysis` 后附上路径和问题。默认纯日志分析；项目可选，需明确提供项目路径或选择当前工作目录。报告可查看主链、时间线、缺失与建议、原文证据。

结果有偏差时，调用反馈技能并提供报告目录，说明实际情况和报告哪里不对。AI 会收集敏感名称并复盘，离线生成 JSON、Markdown，由你检查后自行分享。只分享最新输出目录；同级 `*-LOCAL-ONLY/` 含原值映射，只留本机。

## Beta 限制

机械核验不证明语义因果，日志可能缺失，分析也可能有误；未针对超大日志优化。报告含原始日志，请谨慎分享。反馈默认规则不识别产品、项目、公司、人名及内部模块名，需补充敏感词并人工检查。工具不联网、不上传或发送，后续按真实使用反馈迭代。

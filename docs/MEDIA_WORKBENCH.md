# 手动截图与录屏

适用 Harmony 0.5.0-rc.6。常驻工具为日志、截图与录屏、应用；文件、数据库、命令、测试、语音及后台任务收在“更多工具”，接口与历史保留。

点击面板下方截图或截图快捷键生成手动记录，录屏按钮开始与停止生成手动录像。历史按设备与时间排列，跨聊天会话保留；自动测试和 AI 采样不会混入。旧文件缺来源信息，勾选旧记录才能查看，原文件保留。

点击缩略图或“预览与批注”进入大预览；列表“加入对话”将原图作为当前草稿附件，不发送。预览可画框、箭头、文字、实心打码、缩放和平移；加入时把当前批注渲染成新的 PNG，原图不改。批注仅在本次预览中暂存，关闭后重开不恢复编辑步骤；加入后的图片保留在草稿附件中。视频可播放、选取当前帧，再批注加入对话。

| 快捷键（预览内） | 操作 |
|---|---|
| V / R / A / T / B | 移动 / 矩形 / 箭头 / 文字 / 打码 |
| Ctrl+Z | 撤销 |
| Ctrl+Shift+Z 或 Ctrl+Y | 重做 |
| + / - / 0 / 1 | 放大 / 缩小 / 适应窗口 / 原始比例 |
| Ctrl+Enter | 将当前图片加入对话 |
| Esc | 关闭预览 |

文字输入时保留正常输入与编辑快捷键；Ctrl+Enter 和 Esc 仍有效。输入法组合输入中不触发工具快捷键。快捷键不会在聊天区全局抢占。

批注图片加入对话后，预览窗口自动关闭并把焦点交回目标会话输入框，已有草稿保持不变，可继续补充文字。按钮与 Ctrl+Enter 走同一套提交逻辑：处理中禁用重复点击，连续触发不会产生重复附件。失败时窗口与全部批注保留，显示原因并可重试。

加入时固定发起会话，异步完成不能写入切换后的会话；已有文本、引用、附件保留。忙碌或附件能力不足会显示原因，不用路径代替图片。附件上限 20 MiB；发送前仍需用户自行检查图片及当前模型的图像能力。预览/加入本身不调用模型。

新媒体旁的 .origin.json 记录手动或自动来源，备份时一并保留；旧版本回退忽略该字段。图片与录像不随会话删除自动清理。

# dshE2E 测试工作台

从一个 DSH 会话顶部打开 **dshE2E**。0.2.0 将测试记录、报告和复测集中在这个面板；模型仍使用当前会话的配置。

## 记录与会话

- 默认只显示当前会话。切换会话会清空旧详情、停止旧请求，再读取新会话的记录。
- 列表、详情、日志和文件读取都携带会话范围；AI 工具使用实际调用会话的身份，不能传另一个会话 ID 绕过范围。
- “全部会话历史”是同一电脑使用者主动打开的只读视图，可找回旧记录；归属不明的旧记录不会自动分配到当前会话。
- 按全部、进行中、已通过、未通过、已取消、已中断筛选，支持名称、设备、错误关键词搜索。
- 每页 20 条；超过 30 条的旧报告也可以打开。归档只隐藏记录，不删除报告、截图或日志；可在“已归档”中恢复。

这是本机个人工具的范围约束，**不是多用户鉴权系统**。全部历史仍可由本机使用者主动查看。不要把 DSH 服务无保护地开放到公网。

## 新建与调整复测

1. 点击“新建测试”，填写目标和可从屏幕确认的验收条件。
2. 选择是否采集日志。需要日志时填写应用名称，或已经确认的目标包名；AI 先查询设备上的真实应用。
3. 可调整总时间、每步骤动作、每步骤模型调用上限。高级设置可填写确定步骤 JSON；至少有一项 `assert`。
4. 点击“生成会话草稿”，检查当前会话输入框的内容并发送。**生成草稿并不直接执行测试。**
5. 失败报告中的“调整后复测”带入原参数。确认调整后发送草稿，生成新 ID，并通过 `parentRunId` 关联原报告。

原报告不会覆盖。确定步骤的复测必须同时检查步骤 JSON：只改目标文字不会改变原有确定步骤。未知副作用的动作不会自动重放；失败后的调整由使用者或外层 AI 明确提出。

通过的测试可“复用通过流程”，使用 `replay`。缓存命中仍需重新定位控件和验证结果；不保证所有应用或页面都能命中。

## 报告

| 页面 | 内容 |
|---|---|
| 概览 | 目标、验收、实际状态、耗时、模型调用和动作记录、预算、模型身份、控制释放、日志与失败建议 |
| 步骤与截图 | 每个步骤的结果、观察／模型／动作轨迹、失败位置、可下载的截图与文字证据 |
| 应用日志 | 独立采集状态、应用目标、警告、最低级别、关键词、正文分页、日志下载及 AI 分析入口 |
| 复测记录 | 原测试、调整复测和流程复用的关联入口；每次执行保留自己的结果和参数 |

新测试尽量保存开始前、结束后的两张截图，另外展示运行器实际保存的失败截图。控件树不完整、敏感字段坐标缺失、尺寸不一致或设备不可用时，边界截图不保存并说明原因。取消后不再为补截图发送设备操作。旧报告没有 PNG 时明确提示，不将文字轨迹当作截图。

点击事件的“关联日志”，按本机采集时间筛选该事件前后两秒；它不是设备日志产生时间的精确关联。采集有上限或历史水位不确定时保留警告。

**界面验收和日志采集分别判断。** 有日志不代表任务通过；0 条日志不证明没有缺陷；`error` 级别也不能单独证明应用有缺陷。AI 分析入口会生成读取报告和正文的会话草稿，不在面板内自动修复第三方应用。

## 运行与性能

进行中显示准备、观察、规划、动作、验收或收尾阶段，可停止当前会话的任务。取消后检查报告中的释放结果；不能在另一会话取消或复测该任务。

面板隐藏时停止刷新，恢复时重新读取；请求退出或切换时取消，避免旧响应覆盖新会话。历史列表读取小型 `record.json` 索引，日志和报告按需加载。截图通过 DSH 的文件请求读取为临时对象 URL，离开页面释放；适用于桌面端的 `dsh-app` 协议。

冷启动把磁盘中未完成的任务标记为“已中断”，不会显示永久“进行中”，也不会伪称控制释放已确认。宿主退出后重新打开才能加载新后端；只刷新页面可能出现新前端配旧后端，此时面板会提示版本不一致。

当前尚未提供截图差异标注、完整参数差异比较、独立用例库、批量回归调度或自动修复。关联复测和通过流程复用已经可用。

# 日志工作台使用指南

## 日志入口

| 入口 | 用途 | 需要手机 / AI 吗 |
|---|---|---|
| dshHarmony → 工具 → 日志 | 读取连接设备的实时 HiLog，暂停显示、跟随和现场诊断 | 需要手机；不调用 AI |
| dshE2E → 日志工作台 | 导入本机离线日志、查看日志库 | 不需要手机或模型 |
| dshE2E → 测试报告 → 应用日志 | 阅读该次测试已采集的应用日志 | 阅读时不需要手机或模型 |

候选版 0.5.0-rc.2 / 0.4.0-rc.2 的日志库只显示当前会话，界面和服务端都检查归属。不同会话的文件不混在一起；打开日志工作台后不轮询手机状态或测试报告。文件保存在本机，不自动上传。AI 分析只有用户发送草稿后才由当前会话模型执行，相关日志正文可能成为模型输入。

## 实时日志的布局与应用选择

1. 在 dshHarmony 打开「工具 → 日志」，标题显示插件版本。日志默认占约 70% 工作台宽度；拖动设备与日志之间的分隔条可调整比例，分隔条获得焦点后也可用方向键调整。
2. 标题选择「左右布局」「上下布局」或「专注日志」。专注模式收起设备画面，恢复时点击「显示设备」。比例和布局保存在当前电脑，不影响设备连接。DSH 自身的右栏全屏按钮还能扩大整个插件区域。
3. 展开「应用 / 包名」，输入应用名、包名片段、进程名或 PID，缩小候选范围，再点击或按 Enter 确认。输入搜索不会直接切换过滤目标。每 5 秒刷新进程，刷新不清空搜索和所选包名；无匹配不会自动选第一个应用。
4. 「进程名称 / PID」可进一步细分。TAG / TID / Domain / 时间在「更多筛选」中。筛选仅改变视图，不重启采集。
5. 查找栏默认显示，Ctrl+F 将焦点移到查找栏，Enter / Shift+Enter 或箭头按钮上下定位；查找覆盖当前有限缓冲里的筛选结果。
6. 点击日志行打开详情。拖动详情上边缘调高，方向键调整、双击恢复默认；可最大化、收起、自动换行和复制完整行。详情保留打开时的记录，缓冲淘汰不会换成另一行。

## 保存实时日志

同一处工具栏有「保存日志」和「保存到当前会话」。保存不结束手机操作、不暂停采集，也不启动测试；无需“本次操作”等范围选择。

- 普通保存：采用当前保留且符合筛选的日志原文，UTF-8、CRLF 换行。支持文件选择器时选择位置，否则使用宿主下载流程。与 DevEco 实际导出格式的逐项对照留待验收。
- 会话保存：共用相同的筛选快照，自动命名并放入当前会话暂存目录。成功提示提供「打开日志工作台」，定位这份文件。
- Ctrl+F 只高亮，不缩小保存内容；暂停显示时保存当前显示的保留行。保存开始后新日志不加入该快照。
- 保存记录应用、设备标识、筛选及时间边界、条数、连接累计省略和淘汰数量。累计计数不代表文件时间区间的精确缺失量。
- 缺少会话或 E2E 未提供协议 2 时不能会话保存。先成对更新两个插件并完整重启；不降级写入旧的全局日志库。

## 导入离线文件

1. 在目标会话打开 dshE2E「日志工作台」，拖入一份或多份文件，或点击「导入日志」多选。
2. 选择 UTF-8 TXT、LOG 或逐行 JSONL，单文件最多 32 MiB；更大的文件先按时间切分。支持 HDC 标准 HiLog 以及 DevEco 导出布局。
3. 文件按队列串行导入，浏览器每次读取和发送 256 KiB，服务器逐行解析。一份失败不取消其余文件；可重试仍保留在当前队列的失败文件，或重新选择源文件。可取消当前会话尚未完成的队列。
4. 查看文件来源、大小、识别格式、解析及未解析数量。未识别行保留原文，不冒充结构化 HiLog。原文件完整保存，结构化副本最大 64 MiB；超长行和容量超限明确计数并可下载原始文件。

文件存放在 `DSH_HOME/storages/dshE2E/log-library/sessions/<会话键>/<文件ID>`。同名文件分别保留，不覆盖；来源、排序和文件名搜索用于管理列表。查看器会脱敏已知敏感字段，原始文件按原字节保存，仍需按自己的隐私要求保管。

## 文件管理和回收区

- 每份文件可改名、AI 分析、删除。改名只修改展示名称，不修改内容或 ID。
- 全选覆盖当前来源和文件名筛选的全部分页；选中集合固定，之后新保存的文件不被连带删除。选择超过 10 分钟或被新的选择替换后需重新选择。
- 「清空当前会话」不受列表过滤限制。单份、批量和清空都先进入回收区，成功后可撤销。
- 「回收区与空间占用」可单份恢复，查看原文件和结构化正文的合计占用；数字未含元数据、导入临时文件或文件系统开销。
- 永久清空回收区需再次确认，无法撤销。删除仅作用于插件副本，不能删除导入来源、其它会话或 E2E 测试报告。
- 旧版共享文件通过「更多管理 → 查看待归属旧日志」明确归入当前会话；复制校验并重建源行号，旧副本保留。

## 过滤与查找

- 过滤：按正文、TAG、Domain、PID、TID、最低级别、时间范围缩小结果。Warn 表示 Warn/Error/Fatal，不是仅 Warn。
- 查找：在日志区域点击查找或按 Ctrl+F，高亮并上下定位。它不会删除周围未匹配行。
- Harmony 的查找覆盖当前有限缓冲中符合过滤的日志。E2E 的 Ctrl+F 只查当前页；查整个文件使用过滤栏，然后分页阅读。范围会在界面明确显示。
- E2E 每页最多 100 条且约 24 KiB；长消息有截断提示，可以单条展开至 8192 字符，超过部分仍在原始文件中。筛选导出包含分页以外的匹配行。
- 筛选条件和查找分别有大小写与正则开关。多个字段筛选组合为 AND，正则内 `error|warn` 表示 OR。

正则使用有界子集，不是全部 Java/JavaScript 正则：支持普通字符、锚点、字符类、分支和单个重复量词；不支持分组、环视、反向引用或一个分支多个量词。重复量词后仍有内容时，应使用 `^` 锚定分支起点，例如 `^.*error`。错误模式即时提示，不退回成普通文本匹配。常用示例：`error|warn`、`^Media`、`[0-9]+`。

## 时间和证据边界

Harmony 按设备 HiLog 的 MM-DD HH:mm:ss 时间过滤，支持只填 HH:mm[:ss]、跨午夜范围，不自行添加时区。测试日志按主机收到条目的采集时间筛选；设备原始时间另行显示。导入 HiLog 缺少年份时按最近年份推定并明确警告，不能当作准确历史年份或跨设备同步时间。

测试日志持续落盘，单次任务默认最多 32 MiB；达到容量或写盘队列上限会标记省略数量。异常退出时，已写入 JSONL 可以继续阅读，损坏的末行会给出警告。没有日志、日志被过滤为空、日志曾被截断都不能证明应用没有缺陷。

实时查看器的暂停是暂停显示，不暂停设备输出；隐藏日志面板会停止该连接。缓冲行数和计数文本量均有上限，旧行可能被淘汰。导出的是当前保留行，不能当作完整设备历史。需要持续测试留证时使用 E2E 的任务采集。

## AI 读取

文件旁的「AI 分析」或详情中的「AI 分析此行」填入当前聊天草稿，用户可修改后发送；已有文字会追加保留，含引用或正在提交的草稿不被覆盖。此时不会调用模型、发送消息或操作手机。

发送后 AI 用 `list_log_files/get_file_logs` 读取当前会话文件。行分析引用稳定的原文件行号，默认取前后各 20 行，避免正文筛选隐藏相关上下文；大文件继续分页。`get_logs` 仍用于测试报告日志。文件已删除或不属于当前会话时明确失败，不找同名文件替代。

## 开销与兼容性

Harmony 使用虚拟列表、合批刷新、有限缓存。E2E 使用磁盘 JSONL、流式扫描和有限页面；筛选大文件可能需要等待扫描，连续输入会合并查询。8 MiB 文本、32 MiB 文件等限制是数据边界，不是整个 DSH 进程的内存保证。

DevEco HiLog 的证据和借鉴点见 [REA 研究](RESEARCH_HILOG.md)。没有复制 DevEco 的 Java 实现或 IDE 编辑器组件；字段、过滤、查找及缓冲以插件自有源码实现。

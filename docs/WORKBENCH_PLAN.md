# 日志和手动截图工作台实施计划

更新日期：2026-10-17。本文替代此前方案中目录分组、素材按会话隔离及任务常驻入口的建议。状态将在实际实施和检查后更新。

## 本轮确定行为

1. 日志只按当前会话隔离。单文件、多选、拖放、TXT/LOG/JSONL/JSON、ZIP/GZ 和配套字典均沿用同一导入入口。压缩文件是输入格式，不是用户必须理解的“日志包”或额外目录。列表默认按导入时间倒序，可切换正序；旧目录里的日志一并展示，原始文件与解析来源不丢失。
2. 日志文件可单选、多选分析和回收。移除新建目录、目录按钮、移动目录和临时区概念。后台保留旧目录元数据兼容，不破坏原始数据、旧报告及回退路径。
3. 实时日志目标为最近 100000 行，同时设置文本字节预算，保留虚拟渲染和合批接收。优化增量缓冲，避免每批复制并逐行计量全部历史。测试吞吐、筛选与实际浏览器响应，明确行数上限不等于无条件保留 10 万条超长日志。
4. 任务入口收进更多工具，不作为常驻标签；已运行任务不取消，原接口与数据保留。数据库、命令、测试和语音等高级工具收起。
5. 截图与录屏历史不按聊天隔离，只显示手动按钮或快捷键保存的内容；按设备与时间查看。新记录明确来源，AI 和场景截图不混入；旧来源不明的文件保留在可选旧记录视图，不能擅自认定手动。
6. 点击截图直接预览；列表旁有加入当前对话。预览支持缩放、框、箭头、文字、打码、撤销重做和快捷键。加入对话默认使用当前标注渲染结果，保留原图、原输入和原附件，不自动发送。录屏支持播放及取当前帧加入对话；不承诺所有模型直接理解视频。
7. 目标会话以点击加入时固定，异步结束不能写入切换后的其它会话。附件是实际图片，不用本机路径或剪贴板代替。快捷键仅在预览范围生效，输入文字时不抢键。

## 快捷键约定

预览内：V 移动，R 矩形，A 箭头，T 文字，B 打码；Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做；+/- 缩放，0 适应窗口，1 原始比例，Ctrl+Enter 加入当前对话，Escape 关闭。工具栏展示相同提示；编辑文字、组合输入和宿主聊天不受影响。

# rc.9 / Verify rc.2 交付与验收（2026-10-20）

配套：dshHarmony **0.5.0-rc.9** / dshVerify **0.5.0-rc.2**，tag `v0.5.0-rc.9-e2e-0.5.0-rc.2`。Windows x64、DSH 0.2.0-rc.2、真实 Node24；RC 预发布，原发布资产不覆盖。

## 本次范围

- 修复 Harmony 嵌入会话日志时缺少 flex shell，日志浏览区填满剩余高度。
- 「会话日志 → 全部会话管理」汇总各会话的暂存/回收数量、估算占用与最近导入；支持搜索、分页、跨页多选、移入回收区、恢复、确认后永久清空。
- 清理预览冻结具体文件集合；单次令牌绑定发起会话，10 分钟有效；后来新增文件不加入范围，忙碌会话跳过并报告。普通读取/导出/跨文件搜索的会话隔离不变。
- 按用户反馈移除永久清空的文字输入门槛；查看范围后直接点击按钮执行，保留处理中防重复提交。
- 通过可选 sessionQuery 与实时/持久标题投影读取会话名称，无服务时回退 ID；不启动模型，不读取消息正文生成名称。
- 根安装、AI 安装/升级与两插件文档统一到精确新版本；说明另一电脑的路径发现、原数据保留、独立来源、双 profile、备份、冷启动和回退。

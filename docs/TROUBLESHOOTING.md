# 故障排查

| 现象 | 检查与处理 |
|---|---|
| 插件或模型供应商与另一窗口不同 | 检查启动时 `DSH_HOME` 和 profile；桌面默认 C 盘与自定义 E 盘可能是不同环境 |
| 看不到手机 | 先检查 HDC 在线设备、USB 授权和 Windows 驱动，再检查插件 HDC 路径 |
| 手机提示锁屏 | 在手机上完成身份解锁；无密码时可自动唤醒并滑开，仍会校验是否真的进入可操作页面 |
| 缺少日志目标 | AI 应调用 `resolve_app`，确认后传 `appName` 或 `logAppBundle`；用户不必手查包名 |
| 多个同名应用 | 返回真实候选，不猜测；区分主应用和 launcher，核实对应测试目标 |
| 日志 0 条 | 看具体状态：`empty`、`unconfirmed`、`failed`、`unresolved` 含义不同；不能断言没有报错 |
| 日志只有开头几条 | 0.2.8 修复了界面观察和动作取消日志流的问题；确认宿主确实已重启加载该版本 |
| 日志可能是历史内容 | 检查 `boundary`；`device-log-watermark` 排除水位前条目，`receive-time-only` 明确不能保证全部是本次日志 |
| `partial` | 已收到部分日志但流提前结束；报告保存已收到的条目和警告，不能宣称完整采集 |
| 控件离开屏幕 | 页面可能发生异步更新；派发前失效可有限重新观察，效果不确定的动作不自动重放 |
| 实时视频被占用 | 查看错误中的宿主 PID，结束相应控制；只回收已确认退出的宿主留下的插件专属进程，不清理其他投屏软件 |
| 只有 JPEG 预览 | 静止屏幕可能尚无 H.264 关键帧；画面变化后才能切入视频。预览与视频状态分别显示 |
| HAP 提示 API 不兼容 | 可选 mirror HAP 最低 API 26；API 24 不会通过登录或签名变成兼容，改用本机 DevEco 原生通道或截图 |
| `429` / 模型不可用 | 检查当前模型供应商的额度和返回错误；这与 HDC 设备连接是不同问题 |
| 模型返回错误 JSON | 任务停止并记录原始分类和有界输出摘要，不能把它当作应用缺陷 |

应用日志中的解析失败、网络错误或错误级别只是诊断线索，需结合测试步骤、时间、截图及预期行为判断。没有看到用户需求对应结果，不能仅凭工具执行成功报告通过。

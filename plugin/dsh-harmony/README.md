# dshHarmony

当前0.6.0-rc.1为RC预发布版。配对安装、升级迁移和回滚见[完整指南](../../docs/LOG_ANALYSIS_UPGRADE.md)。

从会话标题栏dshHarmony进入，支持手工设备投屏、截图录屏、批注和实时日志。切会话使用同设备视频Hub。

主干的 protobuf 兼容修复同时保留两份完整原厂视频组件，按设备库的实际符号选择；同为 7.0/API 26 的固件也可能采用不同 protobuf ABI。现有 v0.6.0-rc.1 下载包尚不包含该修复。组件未修改、未重新签名，不替换设备系统库。兼容范围、原厂来源及故障设备待验项见[修复与验收](../../docs/NATIVE_VIDEO_ABI_20261106.md)。

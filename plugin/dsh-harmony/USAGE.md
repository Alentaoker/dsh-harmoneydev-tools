# dshHarmony 使用说明

## 连接与操作

安装后在 DSH 插件列表及会话顶部打开 dshHarmony。手机启用 USB 调试并完成授权；在设置中选择实际 SDK 的 `hdc.exe`，刷新设备并确认在线。只有串口出现不代表 HDC 已连接。

设备面板提供观察、点击、输入、返回、应用、文件、终端、数据库与诊断。AI 使用会话中的 Harmony 工具获取界面和执行已授权动作。

> 查看当前鸿蒙手机页面并截图，说明有哪些可操作控件。

同时安装 dshE2E 时，带结果检查的手机任务交给 `e2e_phone.run`；`status/resolve_app` 只查询。显式直控需 `execution:direct` 和 `directReason`，不会创建 E2E 报告；进行中的 E2E 不允许插入直控动作。详见 [E2E 操作入口](../dsh-e2e/USAGE.md#操作入口与验收范围)。

## 投屏与录像

设置中选择插件原生 H.264，可选低开销、均衡和流畅档位。视频资源随私有包提供，仍需 HDC/驱动与兼容手机；无需安装投屏 HAP 或启动 DevEco Testing。

打开设备页且设备在线、已解锁时自动连接实时视频，日常不需要点“接入实时视频”。画面上的状态会区分：连接中、实时视频流、等待解锁（锁屏或熄屏）、兼容投屏、占用等待、恢复中。手机解锁后立即重连，不再等旧的长时间退避。异常时才用次要的“立即重试”。完整阶段、开销与诊断见 [实时视频连接阶段](../../docs/LIVE_VIEW_PHASES.md)。

同一设备的多个观看窗口和录像共享视频源，手机输入仍受控制租约约束。关闭某个预览只释放自身订阅；最后一个观看者退出才释放视频源。首个订阅决定质量档位，所有订阅退出后重新连接才应用新档位。视频不可用时明确提示并使用截图预览；JPEG 预览不等于实时视频。

「更多工具 → 连接诊断」显示实测的通道、阶段、绘制帧率、跳过依赖帧、首帧与恢复耗时、解码队列和预览积压。这些是测量值，不是估算；“优先硬解”是请求而不是硬解已生效的证据。

## 日志工作台与实时日志

面板顶部固定「设备 / 日志工作台」；工作台内部固定「实时日志 / 会话日志」。首次进入默认当前设备的实时日志，再次进入恢复上次 Tab。实时页常驻，筛选、查找、选中行、滚动与暂停各自保留；切 Tab 不清空缓存，也不清零未接收/淘汰计数；隐藏时停止刷新而采集继续。

实时日志选择应用或进程，再按级别、TAG、Domain、PID/TID、时间及正文筛选。Ctrl+F 在保留的筛选结果中查找，不改变保存范围；Enter / Shift+Enter 下一个 / 上一个匹配；Esc 先关历史再关查找，且不会连带关闭工作台。查找与筛选各保存最近 30 条历史（含正则与大小写开关），点击或方向键选中后按 Enter 复用，可单条删除或清空；只聚焦输入框时 Enter 仍是“执行本次搜索”，修改关键词会取消历史选中，输入法组合输入不触发。**同一份历史由实时日志与会话日志共用**，切换视图后打开历史即可看到。暂停冻结显示，采集仍继续。

「保存到当前会话」依赖配套 E2E 的会话日志协议，成功后出现「查看文件」，直接切到会话日志并选中该文件（一次性定位，之后手动浏览不会被拉回）。会话日志页就是配套 dshE2E 的完整工作台（导入、拖入、删除与回收、改名、压缩包、分页、应用/TAG 筛选、AI 分析），搜索历史与实时视图共用，日志仍在 E2E 存储，不复制。离线文件、已保存日志和 AI 分析草稿见 [日志工作台指南](../../docs/LOG_WORKBENCH.md)。不要把日志条数为零当作没有异常。

# plan 与交接记录

按需选用，并与项目已有的 plan 格式合并；已经确认的内容用链接引用，不重复抄写。小改动给一行证据即可，例如：

`标题：字号 16、字重 500、颜色 font_primary ← 订单详情 / 退款卡片 / 标题（节点 12:345）`

## plan 里的设计依据

每个受影响的区域写一条：

- **区域与状态**：
- **设计来源**：文件、页面、节点，以及为什么对应本需求；还没定位就写下一步怎么找，不填猜测的 GUID
- **取参**：待取参 / 已取参（关键值或链接）。plan 阶段没取参就写“待取参”，不为填表编造数值
- **图标**：不涉及 / 已确认（名称或资源）/ 待用户决定（列出）
- **工程入口**：相关组件或模块
- **待定项**：会阻塞哪个子任务
